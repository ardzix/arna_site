# HTTPS operator pilot qualification
The workflow uses isolated PostgreSQL16 with loopback and owned temporary data. It verifies no other domain rows or existing CRM destination are changed by the audit migration; actual PostgreSQL lock waits, single-use competing acceptance, state/owner/manifest changes, exact receipt expiry recheck, transactional rollback, and the apex-only disable preserving proof. External HTTPS, TLS and OAuth/Vercel authority are not exercised by these synthetic inputs. Separate transport fixtures test pinned numeric address, public-address classification, TLS configuration, no redirects and exact response. See domain-proof-review.md for release gates.
